### Tech stack

Java, Spring Boot, Spring Data JPA, Spring Security, JWT

### Features

- Robust backend for a shop transaction tracking system, integrated with a Flutter frontend.
- Uses JWT for authentication with OTP verification and role-based authorization with Spring Security.
